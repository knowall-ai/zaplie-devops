== Prerequisites

* Node.js 18+ or Bun
* Azure DevOps organization
* Visual Studio Marketplace publisher account

== Local Development

=== Install Dependencies

[source,bash]
----
bun install
----

=== Build Development Package

[source,bash]
----
bun run package-dev
----

This creates a VSIX file: `knowall-ai.zaplie-devops-dev-*.vsix`

=== Build Release Package

[source,bash]
----
bun run package-release
----

This creates a VSIX file: `knowall-ai.zaplie-devops-*.vsix`

== Manual Installation

=== Install in Azure DevOps

. Navigate to your Azure DevOps organization
. Go to *Organization settings* → *Extensions*
. Click *Browse marketplace* → *Manage extensions* (three dots menu)
. Select *Upload new extension*
. Upload the VSIX file

=== Verify Installation

. Open any project in your organization
. Navigate to a work item
. Click the context menu (three dots)
. Verify "Zap" action appears

== CI/CD Pipeline

=== GitHub Actions

The repository includes two workflows:

==== ci.yml

Runs on every push and pull request to `main`:

* Lint check
* Format check
* Build verification

==== publish.yml

Runs on version tags (`v*`) or manual dispatch:

* Builds the extension
* Publishes to Visual Studio Marketplace

=== Required Secrets

Add the following secret to your GitHub repository:

[cols="1,3"]
|===
|Secret |Description

|`MARKETPLACE_PAT`
|Personal Access Token for Visual Studio Marketplace publishing
|===

==== Creating a Marketplace PAT

. Go to https://dev.azure.com/{organization}/_usersSettings/tokens
. Click *New Token*
. Set:
  * Name: "Marketplace Publishing"
  * Organization: "All accessible organizations"
  * Scopes: "Marketplace (Publish)"
. Copy the token and add as GitHub secret

== Publishing

=== Tag-based Release

[source,bash]
----
# Create and push a version tag
git tag v1.0.0
git push origin v1.0.0
----

The workflow automatically publishes to the marketplace.

=== Manual Release

. Go to *Actions* → *Publish Extension*
. Click *Run workflow*
. Select target: `dev` or `release`

== Post-Deployment

=== Share Extension

If the extension is private, share it with specific organizations:

. Go to https://marketplace.visualstudio.com/manage/publishers
. Select your publisher
. Click the extension
. Go to *Share* tab
. Add organizations

=== Verify Deployment

. Install extension in test organization
. Open a work item with an assignee
. Click "Zap" from context menu
. Verify dialog opens correctly
. Configure Lightning address in Organization Settings → Zaplie Settings

== Rollback

To rollback to a previous version:

. Go to marketplace publisher portal
. Select the extension
. Click *Versions*
. Unpublish current version or publish previous VSIX
